# Unit 3 Steganography Activity

## Objective
To hide a secret message inside an image using Python steganography.

## Files
- `cover.png` - Original image
- `secret.txt` - Secret message
- `stegnography.py` - Python steganography program
- `stego_output.png` - Image containing the hidden message

## Technology Used
- Python
- Pillow
- VS Code

## Process
1. Select a cover image.
2. Read the secret message from `secret.txt`.
3. Hide the message inside the image using Python.
4. Generate `stego_output.png`.
5. Extract the hidden message from the output image.
